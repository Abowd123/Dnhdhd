# اصطلاحات الوحدات والإشارات

هذه الوثيقة مرجع مُلزِم: كل ملف في `src/engine/` يتبعها، وأي تعارض بينها وبين
الكود خطأ في أحدهما يجب حلّه لا التعايش معه.

## الوحدات

| الكمية | الوحدة | ملاحظة |
|---|---|---|
| طول | متر (m) | |
| قوة | كيلونيوتن (kN) | |
| عزم | kN·m | |
| معامل المرونة E | جيجاباسكال (GPa) | يُحوَّل داخلياً: `EI = E × 1e6 × I` بوحدة kN·m² |
| عزم القصور I | m⁴ | |
| جساءة نابض | kN/m | |
| إزاحة وترخيم | متر — تُعرض بالمليمتر | |
| دوران | راديان — يُعرض بالمِلّي‑راديان | |

## الإشارات

- **القوى الرأسية**: لأعلى موجب. أحمال الجاذبية سالبة.
- **العزوم**: عكس عقارب الساعة موجب.
- **الإزاحة v**: لأعلى موجب. الترخيم لأسفل سالب.
- **الدوران θ = dv/dx**: عكس عقارب الساعة موجب.
- **قوة القص V**: موجبة حين تكون محصلة القوى الرأسية على الجزء **الأيسر** من
  القطاع متجهة لأعلى.
- **عزم الانحناء M**: موجب عند الترخيم لأسفل (Sagging) — شد بالألياف السفلية.

من هذين يتبع:

```
dV/dx = w(x)        dM/dx = V(x)        EI·v″ = M(x)
```

حيث `w` شدة الحمل الموزع بنفس اصطلاح القوة (لأعلى موجب).

## ترتيب درجات الحرية

درجات حرية العنصر: `[v₁, θ₁, v₂, θ₂]`.

الترقيم العام يمرّ حصراً عبر `DofMap` في `dofmap.ts`، ولا يوجد في المشروع أي
ترقيم ضمني من نوع `node*2 + i`. السبب: المفصل الداخلي يُنتج عقدة بدرجتَي دوران
وإزاحة رأسية واحدة مشتركة، وأي ترقيم ضمني ينكسر معه.

## قوى نهايات العنصر

`f = k·d − f_eq` حيث `f_eq` الأحمال العقدية المكافئة للحمل الموزع. الربط
باصطلاح المنحنيات:

```
V(x₀⁺) = +f[0]        M(x₀⁺) = −f[1]
V(x₁⁻) = −f[2]        M(x₁⁻) = +f[3]
```

## قواعد الوثب عند العقدة

مُشتقة من توازن جزء الكمرة الأيسر:

```
ΔV = P + R_Fy               (P حمل مركز، R_Fy رد فعل رأسي)
ΔM = −(M_app + R_Mz)        ← لاحظ الإشارة السالبة
```

إشارة وثب العزم السالبة موضع خطأ شائع، ولها اختبار صريح في
`tests/internalForces.test.ts`.

## الاستمرارية والانفصال

| الكمية | تنفصل عند |
|---|---|
| V | الحمل المركز، ورد الفعل الرأسي |
| M | العزم المركز، ورد الفعل العزمي (تثبيت تام) |
| θ | المفصل الداخلي فقط |
| v | لا تنفصل أبداً |

الانفصال حقيقي فيزيائياً لا عيباً في الرسم، لذلك يُرجع `evaluateAt` قيمتين
(`left` و`right`) ويُصدِر مولّد نقاط الرسم نقطتين بالمحور السيني نفسه، فيرسم
الخط وثبة رأسية. إغفال هذا هو سبب ظهور مخطط قص **مائل** خاطئ عند الأحمال
المركزة في كثير من الأدوات.

## اصطلاح العرض

- **العزوم**: مفتاح تبديل في الواجهة بين الرسم على **جهة الشد** (الموجب لأسفل —
  العرف السائد في الهندسة المدنية) وبين الاصطلاح الرياضي (الموجب لأعلى).
- **منطقة الرسم LTR** داخل واجهة RTL: المخططات الإنشائية تُقرأ من اليسار لليمين
  عالمياً، والانعكاس يقتصر على النصوص والقوائم.
- **الأرقام لاتينية** (0‑9) لا عربية‑هندية، وفق العرف في المخرجات الهندسية.

## نسبة الترخيم L/δ

تُحسب على الترخيم **النسبي إلى وتر المسندين**، لا المطلق: الهبوط الجسمي الصلب
لا يُحدث إجهاداً ولا يخصّ قابلية الخدمة. الترخيم المطلق يُعرض في عمود منفصل.

الطول المرجعي للكابولي = ضِعف طوله البارز (عرف شائع لا قاعدة عامة)، مضبوط من
الوسيط `cantileverFactor` في مكان واحد.
